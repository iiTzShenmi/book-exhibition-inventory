### Clean Generated Reports
```bash
# Reports are regenerated on each check
rm database/tools/reports/*.tsv
```

### Clean Log Files
```bash
# Log files are temporary and safe to delete
rm database/logs/*.txt
```

### Clean Python Cache
```bash
# Remove Python cache files
find database -type d -name __pycache__ -exec rm -r {} +
find database -name "*.pyc" -delete
```

## Directory Organization

### `/database/backups/`
- **Purpose**: Store database backups
- **Files**: `.db`, `.csv`, `.sql` files
- **Cleanup**: Keep last 7-30 days, archive older ones
- **Git**: Not tracked (in `.gitignore`)

### `/database/logs/`
- **Purpose**: Temporary log files and missing data reports
- **Files**: `.txt` files generated by tools
- **Cleanup**: Safe to delete anytime
- **Git**: Not tracked (in `.gitignore`)

### `/database/tools/reports/`
- **Purpose**: Generated diagnostic reports
- **Files**: `.tsv`, `.csv` files from `check` command
- **Cleanup**: Regenerated on each check, safe to delete
- **Git**: Not tracked (in `.gitignore`)

### `/database/`
- **Purpose**: Core database files
- **Files**: `inventory.db`, `inventory.csv` (local dev only)
- **Cleanup**: Keep for local development
- **Git**: Not tracked (in `.gitignore`)

## Maintenance Schedule

### Daily
- Check for new backups (automatic)
- Review logs if issues occur

### Weekly
- Clean old backups (keep last 7 days)
- Clean generated reports
- Clean log files

### Monthly
- Archive old backups
- Review backup retention policy
- Clean Python cache files

## File Size Management

### Large Files to Watch
- `inventory.db` - SQLite database (can grow large)
- `backups/*.db` - Backup files (can accumulate)
- `backups/*.sql` - SQL dumps (can be large)

### Recommendations
- Keep only essential backups
- Compress old backups before archiving
- Monitor disk space regularly
